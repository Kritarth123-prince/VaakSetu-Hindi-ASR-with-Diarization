# VaakSetu
## Hindi ASR with Speaker Diarization and Confidence Scoring

---

## Project Overview

VaakSetu is an end-to-end Hindi Automatic Speech Recognition (ASR) system built on the
**AI4Bharat XLSR (wav2vec 2.0)** model, finetuned on an **880-sample Hindi speech dataset**
using Connectionist Temporal Classification (CTC) loss.

The inference pipeline adds:
- **Speaker Diarization** — who spoke when (pyannote.audio 3.1)
- **Confidence Scoring** — per-segment CTC confidence score (0–1)
- **Punctuation Restoration** — commas, periods, capitalisation
- **SRT / VTT subtitle output** — speaker-labelled timestamps
- **Batch processing** and **real-time folder monitoring** modes

> **Finetuning was performed on Yotta / DGX4 servers with NVIDIA A100/V100 GPUs.**

## Project Structure

```
vaaksetu/
├── inference.py          ← Full inference pipeline (run this for transcription)
├── finetune.py           ← Finetuning script (AI4Bharat XLSR on Hindi dataset)
├── requirements.txt      ← Python dependencies
├── README.md             ← This file
│
├── config/
│   ├── ai4b_xlsr.yaml    ← wav2vec 2.0 model config (required)
│   ├── dic.ltr.txt       ← Grapheme dictionary (required)
│   └── vocab.json        ← Auto-generated by finetune.py --vocab-only
│
├── model/
│   └── checkpoint_best.pt  ← Finetuned model checkpoint (required)
│
├── dataset/              ← (finetuning only)
│   ├── dataset.csv       ← Columns: filename, ground_truth
│   └── audio/            ← Audio files referenced in dataset.csv
│
├── input/                ← Drop audio files here (monitor mode)
├── transcripts/          ← All outputs saved here
└── chunks/               ← Temporary chunk files (auto-cleaned)
```

## Installation

```bash
# 1. Clone / download the project
cd vaaksetu

# 2. Install dependencies
pip install -r requirements.txt

# 3. For diarization — accept the pyannote model licence on HuggingFace:
#    https://huggingface.co/pyannote/speaker-diarization-3.1
#    Then export your token:
export HF_TOKEN=your_huggingface_token_here
```

## Running Inference

### Monitor Mode — watches input/ for new files (default)
```bash
python inference.py --hf-token $HF_TOKEN
```

### Batch Mode — process all files in input/ at once
```bash
python inference.py --batch --hf-token $HF_TOKEN
```

### Disable optional modules
```bash
python inference.py --no-diarization          # skip speaker diarization
python inference.py --no-punctuation          # skip punctuation restoration
python inference.py --no-diarization --no-punctuation  # transcription only
python inference.py --cpu                     # force CPU (no GPU)
```

### Custom paths
```bash
python inference.py \
  --config     /path/to/ai4b_xlsr.yaml \
  --dictionary /path/to/dic.ltr.txt \
  --checkpoint /path/to/checkpoint_best.pt \
  --input-dir  /path/to/audio/folder/ \
  --batch
```

## Output Files

For each input file `audio.wav`, four files are produced in `transcripts/`:

| File | Description |
|------|-------------|
| `audio.txt` | Plain transcript with speaker, timestamps, confidence |
| `audio.srt` | SRT subtitle file (compatible with VLC, YouTube) |
| `audio.vtt` | WebVTT subtitle file (compatible with HTML5 video) |
| `audio.json` | Full metadata: speakers, segments, confidence, timing |

### Sample `audio.txt`
```
File       : input/audio.wav
Speakers   : 2
Confidence : 0.9134
============================================================
[SPEAKER_00] (0.00s–4.50s) [conf:0.91] नमस्ते, आप कैसे हैं?
[SPEAKER_01] (5.10s–9.80s) [conf:0.88] मैं ठीक हूं, धन्यवाद।
```

### Sample `audio.srt`
```
1
00:00:00,000 --> 00:00:04,500
[SPEAKER_00] नमस्ते, आप कैसे हैं?

2
00:00:05,100 --> 00:00:09,800
[SPEAKER_01] मैं ठीक हूं, धन्यवाद।
```

## Running Finetuning

> **Note:** Finetuning requires a GPU. It was performed on Yotta / DGX4 servers.

```bash
# Step 1 — Build vocabulary only (verify dataset loads correctly)
python finetune.py --vocab-only

# Step 2 — Full finetuning (30 epochs, batch size 8)
python finetune.py

# Step 3 — Custom configuration
python finetune.py \
  --csv       dataset/dataset.csv \
  --audio-dir dataset/audio/ \
  --epochs    30 \
  --batch-size 8 \
  --lr        1e-4
```

### Dataset CSV Format
The CSV file must have exactly these two columns:

```csv
filename,ground_truth
speaker1_001.wav,नमस्ते आप कैसे हैं
speaker1_002.mp3,मैं ठीक हूं धन्यवाद
```

## CLI Reference

### inference.py
| Flag | Default | Description |
|------|---------|-------------|
| `--batch` | off | Batch mode (process all files at once) |
| `--no-diarization` | off | Disable speaker diarization |
| `--no-punctuation` | off | Disable punctuation restoration |
| `--cpu` | off | Force CPU inference |
| `--hf-token TOKEN` | None | HuggingFace token for pyannote |
| `--input-dir PATH` | `input/` | Audio input directory |
| `--config PATH` | see code | Path to ai4b_xlsr.yaml |
| `--dictionary PATH` | see code | Path to dic.ltr.txt |
| `--checkpoint PATH` | see code | Path to checkpoint_best.pt |

### finetune.py
| Flag | Default | Description |
|------|---------|-------------|
| `--csv PATH` | `dataset/dataset.csv` | Dataset CSV |
| `--audio-dir PATH` | `dataset/audio/` | Audio files directory |
| `--output-dir PATH` | `finetuned_model/` | Checkpoint output directory |
| `--epochs N` | 30 | Number of training epochs |
| `--batch-size N` | 8 | Per-GPU batch size |
| `--lr FLOAT` | 1e-4 | Learning rate |
| `--no-fp16` | off | Disable mixed precision |
| `--cpu` | off | Force CPU training |
| `--vocab-only` | off | Build vocab.json and exit |

## Key Technical Decisions

| Decision | Rationale |
|----------|-----------|
| Freeze CNN encoder during finetuning | Prevents overfitting on 880 samples |
| CTC loss (no forced alignment) | Audio frame ↔ character alignment not required |
| 30-second audio chunking | Fits GPU VRAM; handles long recordings |
| File size polling before processing | Prevents partial-file errors in monitor mode |
| Confidence = avg per-frame max softmax | Directly derived from CTC output — zero overhead |
